# Participium-Civic-Engagement-Platform
Full-stack civic engagement platform developed collaboratively as part of a university Software Engineering course at Politecnico di Torino. Built using React, TypeScript, Flask, and REST APIs, featuring geolocated issue reporting, role-based workflows, notifications, and automated testing.



**University Group Project | Software Engineering | Politecnico di Torino**

## Overview
Participium is a full-stack web application designed to improve communication between citizens and local municipalities by enabling users to report and track urban issues.

The project was developed collaboratively as part of the Software Engineering course at Politecnico di Torino.

## Technologies
- **Frontend:** React, TypeScript
- **Backend:** Python, Flask, REST APIs
- **Mapping:** OpenStreetMap
- **Testing:** Pytest, Selenium, Postman

## Key Features
- Geolocated citizen issue reporting
- Role-based access and management workflows
- Report status tracking
- Notifications and communication features
- Interactive map integration
- Automated testing
